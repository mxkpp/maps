## About

Hobby QGIS maps and related scripts for data munging and exporting.


## Usage

See [scripts/stcofips_42045_trails/docker-run.sh](scripts/stcofips_42045_trails/docker-run.sh), which is executable **from the repo root.**

See [Using PyQGIS in standalone scripts](https://docs.qgis.org/3.38/en/docs/pyqgis_developer_cookbook/intro.html#using-pyqgis-in-standalone-scripts) which is the basis of context manager class `QGISHeadless` in [scripts/utils.py](scripts/utils.py)
